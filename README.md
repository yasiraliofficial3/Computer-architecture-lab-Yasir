# NASM Assembly Language Tasks

20 NASM Assembly tasks for 32-bit Windows using NASM and GCC/MinGW.

## Build and Run

Open Command Prompt and run:

nasm -f win32 task1.asm -o task1.obj
gcc task1.obj -o task1.exe
task1.exe

Repeat with the desired code number.

## Files

task1.asm to task20.asm
